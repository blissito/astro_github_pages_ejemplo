🔧 Claude SDK - Parte 1

Instalación y configuración básica

# Instalación del SDK
npm install @anthropic-ai/sdk

# Configuración de API Key
export ANTHROPIC_API_KEY="sk-ant-..."

Ejemplo básico de uso:

import Anthropic from '@anthropic-ai/sdk';

const claude = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});

const response = await claude.messages.create({
  model: 'claude-3-5-sonnet-20241022',
  max_tokens: 1024,
  messages: [{
    role: 'user',
    content: 'Genera documentación para esta función'
  }]
});

🤖 Implementación de Subagentes

// subagents/document-generator.ts
export class DocumentGenerator {
  async generateDocs(filePath: string): Promise {
    const code = await readFile(filePath);
    
    const response = await claude.messages.create({
      model: 'claude-3-5-sonnet-20241022',
      system: 'Eres un experto en generar documentación técnica',
      messages: [{
        role: 'user',
        content: `Genera documentación para:\n${code}`
      }]
    });
    
    return response.content[0].text;
  }
}

// Uso con Task tool
await Task({
  description: "Generar docs",
  prompt: "Genera documentación para todos los archivos .ts",
  subagent_type: "document-generator"
});

📝 Scripting Avanzado

Automatización de flujos de trabajo

#!/usr/bin/env node
// claude-docs.js

import { exec } from 'child_process';
import { promisify } from 'util';

const execAsync = promisify(exec);

async function generateProjectDocs() {
  // 1. Analizar archivos modificados
  const { stdout } = await execAsync('git diff --name-only HEAD~1');
  const files = stdout.split('\n').filter(f => f.endsWith('.ts'));
  
  // 2. Generar documentación para cada archivo
  for (const file of files) {
    console.log(`📝 Procesando ${file}...`);
    await execAsync(`claude-code analyze ${file} --output docs/`);
  }
  
  // 3. Actualizar índice
  await execAsync('claude-code index docs/ --format markdown');
}

generateProjectDocs();

🚀 CI/CD con GitHub Actions

Pipeline de documentación automática

# .github/workflows/docs.yml
name: Generate Documentation

on:
  push:
    branches: [main]
  pull_request:

jobs:
  documentation:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Claude SDK
        run: |
          npm install @anthropic-ai/sdk
          echo "ANTHROPIC_API_KEY=${{ secrets.CLAUDE_KEY }}" >> $GITHUB_ENV
      
      - name: Generate Docs
        run: npm run generate:docs
      
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./docs

🔑 GitHub Key con Plan Max

Configuración especial para Claude Pro Max

  1. Ve a GitHub Settings → Developer settings
  2. Crea un Personal Access Token (classic)
  3. Permisos requeridos:
    • repo - Control total de repositorios
    • workflow - Actualizar GitHub Actions
    • write:packages - Publicar paquetes
  4. En Claude Code: claude-code config github.token YOUR_TOKEN
$ gh auth login --with-token < token.txt
$ claude-code mcp install github
